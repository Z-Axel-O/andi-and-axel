# 给彭安迪的1000次心动 ♡

一份王劲杰写给彭安迪的中文互动惊喜网站。

## 使用

直接打开 `index.html` 即可游玩（无需 API、账户或服务器）。若在线分享：把 `index.html` 上传到 GitHub 公共仓库根目录，然后在 Settings → Pages 中选择 Deploy from a branch / main / root。

## 内容

- 7道中文互动选择题（所有选项都有可爱回应）
- 解锁手写风情书
- 可手动点击或自动播放的 **1000次我爱你** 计数体验
- 满1000次解锁终极惊喜、专属约会券和小承诺
- 飘浮爱心、庆祝彩纸、手机自适应

页面没有上传或收集个人信息。Google Fonts 需要网络；离线时会使用系统字体。
